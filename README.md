# The Block

The Block is a simple dodge-and-survive game made using Python and Pygame.
You control a green block at the bottom of the screen, and blue enemy blocks fall from the top.
Move left or right to avoid them — if any block hits you, the game ends.
<br>
You earn 1 point for every enemy block that passes the screen without touching you.
As your score increases, the enemies start falling faster, making the game harder over time.
<br>
The goal is simple: survive as long as possible and get the highest score.
